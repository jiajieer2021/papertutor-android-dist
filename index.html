装之前请在手机上允许「安装未知来源应用」。

安装步骤

  1. 用手机浏览器打开本页，点上面的「下载 APK」；
  2. 下载完成后点通知或文件管理器里的 cuotimiao-v1.52.0.apk；
  3. 系统提示"未知来源"时，允许浏览器/文件管理器安装；
  4. 安装完成后打开「错题喵」，先进「设置 → AI 模型」填 Base URL / API Key。

首次使用需要配置

  • AI：任意 OpenAI 兼容服务（DeepSeek / 通义 / 智谱 / Ollama…），文本与视觉可分别填；
  • 打印机：喵喵机 P2S / C1，蓝牙连接后打印自检页确认；
  • 没有视觉模型时，打开「有本地文字就不传图片」，只用本地 OCR + 文本模型也能识别。
